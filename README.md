# EH Electric & HVAC — LJV-structure-inspired Next.js site

A production-style Next.js App Router project recreating the *information architecture, page structure, component patterns, interaction model, and visual rhythm* observed on ljvdevelopment.com, while using original brand copy and non-proprietary imagery.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Lucide icons

## Routes
- `/`
- `/services`
- `/portfolio`
- `/about`
- `/opportunity`
- `/founder/story`
- `/contact`
- `/contact/consultation`
- `/privacy`
- `/terms`
- `/founder` redirects to `/founder/story`

## Run
```bash
npm install
npm run dev
```

## Notes
Replace the Unsplash image URLs and demo contact information with your licensed brand assets before production use. Forms are UI-only and intentionally do not submit to a backend.
